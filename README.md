# Real-Time Chat Application 

A simple chat application built with Java.

This project is currently under development. I am building it step by step, starting with the basic Java chat logic. The current version is not the final version, and new features and improvements will be added as I continue working on it.


##  Current Features

- Create users
- Send messages between users
- Display sent messages
- Basic object-oriented project structure

##  Technologies

Currently:

- Java
- Object-Oriented Programming (OOP)

Planned:

- Spring Boot
- WebSocket
- MySQL
- REST API
- Authentication
